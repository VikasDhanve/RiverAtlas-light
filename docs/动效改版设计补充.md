# 动效改版设计补充

日期：2026-11-06。适用版本：RiverAtlas v1.1.0。

本轮是既有视觉系统内的普通扩展。依据用户“动画少、图片小、不要制作说明、首页山河要动”的实际反馈，扩大图件展陈并增加可控动态。它沿用已有深海蓝/青蓝、中文离线字体、真实业务原件、1600×900画布及小屏纵向阅读，不重建视觉世界，也不补造新概念、效果图或用户额外批准。

F1修正已将本轮实际角色与组件最小merge至[DESIGN.md](../DESIGN.md)和[设计侧车](../.impeccable/design.json)，保留原世界与普通字体；主线程已备份v1.0设计记录。本补充继续记录增量和历史对照，与[最新方向合同](演示方向合同.md)及[动效编排](动效编排.md)一起阅读。产品范围仍以[PRODUCT.md](../PRODUCT.md)为准。

## 本轮实际媒体角色与布局

以下数值均从`src/styles.css`现行覆盖规则提取，只约束本轮图文/文书展陈变体，不替代全部业务页的原字号。

| 角色 | v1.1实际值 | 使用范围 |
|---|---|---|
| 媒体页主标题 | 43px；继承主标题650字重、1.25行高和原字体栈 | `gallery`、`expert`布局的媒体页；不改变封面和普通业务标题 |
| 媒体页导语 | 22px；底间距16px | 媒体页主标题下方 |
| 媒体页内边距 | 22px 36px 18px | 给右侧图件保留更大面积 |
| 讲解与展台 | 310px固定讲解栏 + `minmax(0,1fr)`展台；列间距30px | 图文展陈与审核页的政策文件视图 |
| 讲解小标题 | 24px；下间距8px | 讲解栏中的信息组 |
| 讲解正文 | 21px、1.6行高、`#d7e6ed` | 讲解栏正文；字族继续使用微软雅黑/等线/中文系统后备 |
| 讲解分组 | 无侧边装饰线、左内边距0；组间距22px | 以青蓝小标题和组距保持定位；F2已移除先前2px左边框 |
| 文书展台 | 两列等宽，间距18px；透视1400px | 当前原件属于文书组且有可配对文书时，两页并列完整容纳 |
| 文书承托面 | 内边距5px、圆角2px、投影`0 12px 30px #0005` | 当前展台中的文书；并列底色为`#f5f6f4` |
| 会议照片承托面 | `#0b2437`，不加投影 | 会议与现场照片，图像仍完整容纳 |
| 数字切换标签 | 宽度38px、内边距5px、圆角4px、字号16px | 用短数字标签为大图让位，完整名称仍在可访问名称与图注中 |
| 专注图件按钮 | 字号16px、内边距5px 12px、边框`#42677f` | 展台下方，直接切换专注状态 |
| 图注 | 17px、字距`.02em` | 保留当前图件名称 |

“专注图件”即时收起当前页标题、导语及讲解栏，展台变为一列占满可用宽度；“显示讲解”恢复。章节与工具栏仍在，原件按钮、图号切换及完整原件阅读入口保留。它扩大已有内容，不生成补全原图，也不把原件裁切为装饰。

第19页增加“程序演示 / 政策文件”切换。政策视图将省本级办法及程序条款直接展为两份文书，保留省本级语境；不能把它解释为当前项目实际办理状态。

### 小屏回退

767px及以下仍为纵向阅读：媒体主标题33px、导语18px，讲解小标题21px、正文18px。讲解和图件转单列，并列文书改上下排列；展台最小高度350px、普通图件面最小高度330px、并列文书每份最小高度400px，工具与标签可换行。它沿用原小屏行为，不把固定画布等比压成手机缩略图。

## 本轮动态与视觉深度

| 场景 | 当前编排 | 控制与事实边界 |
|---|---|---|
| 首页、结束页山河背景 | 原生WebGL基于同一背景纹理作水面UV波纹、微光、缓慢镜头与山体轻微视差 | 持续环境动态；不改变业务图件、不代表流速或真实GIS |
| 封面文字 | 32px纵向入场、1.1秒、180ms错位；线条在0.5秒位置开始、1.2秒展开 | 完整名称与月份保留，操作立即可用 |
| 普通标题与导语 | 18px纵向入场、650ms、120ms错位 | 与内容建立顺序，不延迟控件操作 |
| 信息组 | 26px纵向入场、700ms、90ms错位 | 按现有业务组编排；不是逐字生成 |
| 图件展台入场 | 30px纵向位移、0.965倍归位、1.05秒 | 白色证据面和完整原图是主角 |
| 图件手选/序列切换 | 24px纵移、7度Y轴归位、0.96倍归位；850ms、120ms错位 | 显式播放每3.2秒切到下一图；手选中断旧序列，只保留当前切换 |
| 底图概念叠层 | 90px横向入场、1.2秒、180ms错位；选中层再横移至-22px、放大1.045倍，700ms | 图层仅表达资料关系；保留分层示意文字 |
| 流程节点 | 分步时由9px抬升归位，550ms；顶端青蓝3px线以650ms展开；进度连线850ms | 人工分步或每阶段1.5秒播放；高亮不表示办理完成 |
| 草案面积条 | 入场1.4秒、160ms错位；显式重播沿用900ms | 完整数值始终显示，保留草案语境 |

除了文书投影，概念层增加32px网格及`0 16px 32px #0004`投影；面积条高度扩至16px并增加浅色横向渐变。这些是当前场景的表现增量，不把全局内容页改成漂浮卡片；F1已把三类实际投影及用途同步到当前侧车。

### 封面材质与比例

封面背景是原稿自带装饰山河图，原图含AI生成标记，**不能称为真实大连河流实拍**。水面、山体和流光是视觉演绎，不是水文模拟、真实空间数据或项目成果证据。正文地图、文书和现场照片继续承担业务证据角色。

绘制缓冲固定1440×672，通过请求动画帧并以至少32ms绘制间隔约束为约30帧调度目标；不是会议设备达到该帧率的保证。着色器按原图2848×1600比例与宿主宽高计算裁切，保留图像比例，小屏采用局部取景，不把山河拉宽或压扁。原始图像字节未改，离线纹理复用同一背景，不在本文读取或抄录base64内容。

封面遮罩当前为左深右浅的双层渐变，保障名称在持续环境动态前可读；不把背景作为实际地名或测量结果展示。

## 中断、静态与降级

- 暂停/继续覆盖主时间轴、图件切换、地图聚焦、步骤强调和山河背景。后台或打开资料、原件、帮助自动暂停；返回后手动继续。
- 重播重置当前演示；多图从首图起，背景时间归零。跳过推进当前编排终态、停止背景，流程切到末讲解位置；不会自动翻页。
- 系统减少动态和手动静态关闭持续运动与空间入场，内容仍可读，人工切图和分步仍可用。系统减少动态优先，界面不能强制恢复运动。
- 暂停后翻页直接显示完整新内容，不把新页停在不可见入场起点。没有GSAP时保留静态阅读。
- 无WebGL或上下文丢失时保留原背景图并回退轻缓运镜；静态或暂停仍控制回退镜头。回退镜头为24秒循环，从1.04倍到1.10倍再归位，并作轻微位移，不冒充WebGL波纹仍然存在。
- 离页销毁旧WebGL纹理、缓冲、程序及画布；翻页杀死旧时间轴，避免多页背景和文书序列叠加。

| v1.0归档中的首版描述 | v1.1现状及适用解释 |

| 证据面10px圆角、12px内边距；只有弹层投影 | 文书展台改2px圆角、5px内边距并增加文书投影，概念层也新增投影；旧“只有弹层投影”为首版历史 |
| 220ms单一容器短入场，子项不排队 | 增加按业务组、图件与文书的分层入场及显式播放，详见上表和最新编排文档 |
| 键盘翻页不动效 | 当前方向键翻页仍立即响应并聚焦标题，但可触发当前入场；目录选择和hash跳转明确不播放入场。暂停、静态与系统减少动态时直接可读 |
| 封面一次1600ms小幅归位，结束后静止 | 首页和结束页现为可控持续环境动态，加独立文字入场；停止及降级受统一控制 |
| 原河流封面/影像的泛称 | 校准为含AI生成标记的原稿装饰背景；不将其归入真实大连河流实拍证据 |

上述差异是本轮用户反馈触发的实际扩展。F1已最小merge当前`DESIGN.md`和侧车，v1.0历史记录由主线程备份；F2已从产品移除2px讲解左线，保留标题与组距。文档角色没有修改产品或`docs/动效编排.md`。[本轮独立审查](动效改版独立审查.md)文末已将F1/F2评为resolved；ship仅覆盖两项修复评分。
