# 第一版验证报告

日期：2026-11-06。版本：RiverAtlas 1.0.0。交付范围：首版HTML演示供业务审阅，不代表自然资源确权项目完成全部登记手续或通过用户最终验收。

## 内容与来源

- 30页讲解、六章导航，35页原稿均有对应讲解页及完整资料入口。
- 39个业务原件在浏览器中逐一打开、缩放并关闭返回，43个原始图像文件SHA256与提取时一致。
- 主页面、详情、原件共同覆盖四类边界、八步实施、六类成果及六项报告、四类审核/九组分工/七项登记审核、公告期限与发布留档、登簿前置条件及图属档一致。
- 大沙河数据明确草案示例；广西贺江、南京清流河明确外地样例；历史资质与省本级办法保留日期/层级语境。
- 文件原稿SHA256与首次读取相同，原始PPTX未改写。详见source-manifest及内容覆盖验收。

使用本机Chrome/Chromium与Playwright自动化，直接file协议打开，未启动本地服务。

| 完整资料与目录 | 35页全文/表格，六章跳转、30页目录及搜索/无结果反馈 | 通过 |
| 讲解控制 | 暂停/继续、下一步、重播同步回到首步、跳过及快速离页中断 | 通过 |
| 静态 | 系统减少动态效果、手动静态、无动画直接分步 | 通过 |

尺寸：1366×768、1920×1080、2560×1440、3840×2160、3440×1440、390×844。桌面/超宽按画布缩放，小屏纵向阅读。截图在`.impeccable/review/`，保留30页总览、主要尺寸截图、原稿资料、原件缩放、流程暂停及面积条动画中间帧。

首轮发现地图控制区、审核表、七项审核和图表合计区越界，已调整布局和密集字号后复验通过，未删业务内容。过程回归还发现重播依赖下一动画帧才复位，已改为同步复位，最终7项测试全部通过。

## 动效与视觉审查

独立审查见`独立审查.md`：产品/渲染/交互范围disposition为ship，无material finding，可交付首版业务审阅。机械检测仅运行一次，原件查看器初始src和有色阴影提示已修正，浮层改为中性色且去除重复边框阴影。该审查未宣称完成完整Impeccable概念seed工作坊。

| 初始问题 | 修正后 | 原因 |
|---|---|---|
| 密集内容越过画布 | 四处页面重新分配空间，原件和文字保留 | 讲解控制可点击，表格可读 |
| 图层文字被上层遮挡 | 图层使用不透明平面，标签放到露出边缘 | 保持分层含义清晰 |
| 重播首步等待下一帧 | 点击重播同步定位第一步 | 即时反馈，避免快速连续操作读到旧步骤 |
| 静态时播放按钮仍显强调色 | 静态禁用态改为次要色 | 可用性与视觉状态一致 |

## 本次安全检查

采用本地固定版本GSAP，无CDN/字体/地图/接口请求。来源文本以textContent和原生DOM创建，不使用innerHTML、eval、字符串事件或动态远程脚本。hash严格解析并钳制页码。未引入登录、上传、凭据、Web Storage或跨窗口消息。

入口使用meta CSP：connect/object/form禁止，脚本只允许本地self；样式内联例外用于受控GSAP属性和图表布局。meta CSP不能替代服务器响应头，工程本身未部署服务器。运行依赖`npm audit --omit=dev`报告0项已知漏洞；三份自有前端JS语法检查通过。此项不是专业渗透测试或第三方安全验收。
