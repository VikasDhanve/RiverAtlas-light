# 动效编排（v1.4.0）

根据用户明确反馈扩展首版动效与图件展示，沿用本地GSAP 3.15.1，封面增加原生WebGL。无需服务或外部资源。完整来源说明保存在资料阅读层，演示主画面保留必要业务标识。

| 场景 | 展现形式 | 节奏与控制 |
|---|---|---|
| 首页与结束页 | 同一山河背景的水面UV波纹、移动微光、缓慢运镜与轻微山体视差 | 持续环境动态，约30帧上限；暂停、重播、跳过、静态与后台暂停均覆盖 |
| 封面文字 | 业务名称、项目类型、线条及日期依次建立 | 1.1秒主入场，180ms错位；操作不等待 |
| 政策文书 | 双页展陈、完整容纳、大幅阅读面 | 图像切换850ms归位；显式播放每3.2秒换一份；手选中断自动序列 |
| 图件与照片 | 窄讲解栏、大幅展台、专注图件、原件缩放 | 普通入场1.05秒；“专注图件”即时收起标题和讲解，原件可进一步放大 |
| 工作底图 | 有真实图件内容的四层立体展开/合拢，所选图件可查看 | 人工选层，550ms变换、300ms指针视角；不自动轮换 |
| 审核/质检流程 | 节点抬升、顶部强调线及进度连线推进 | 每阶段1.5秒，连线850ms；不自动翻页，不代表办理完成 |
| 面积结构 | 比例条分组生长 | 入场1.4秒、160ms错位；完整数值始终可读。显式播放可重播 |
| 其余业务布局 | 按信息组建立顺序，避免所有元素同时出现 | 导语/标题650ms；内容组700ms、90ms错位 |
| 控件 | 定位、选中与键盘焦点反馈 | 不等待内容动效；减少动态及静态关闭空间运动 |

## 中断与降级

翻页杀死旧时间轴并销毁旧背景场景；文书切换只保留当前一次过渡。暂停覆盖主时间轴、图件过渡、地图、步骤动画和背景。打开资料、原件、帮助或切后台时自动暂停，返回后手动继续。暂停状态翻页直接显示完整内容，避免新页停在不可见的入场起点。

手动静态及系统prefers-reduced-motion保留全部内容和人工步骤。缺少WebGL时保留原图并用轻缓运镜回退；没有GSAP时静态展示。源背景内嵌同一原图字节作为离线纹理，不使用file协议跨源纹理加载，不改变assets/originals。

背景是原稿自带装饰图，带有AI生成标记，不描述为大连实拍、真实GIS或真实流速。原图、文书、图例不做内容修补、生成补全或裁切；原件查看器完整保留。

## 验证边界

Chrome file协议离线测试覆盖背景帧更新、暂停后帧不再增加、继续/静态、无WebGL回退、文书序列中断、暂停翻页可见性、全部39业务图像主页面入口及双页展陈尺寸。六尺寸×30页布局和原件全量打开另见验证报告。动画录屏和中间帧位于.impeccable/review，不替代会议设备实际帧率验证。
