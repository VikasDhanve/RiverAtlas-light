# 第八页固定预览与平滑切换验证

2026-11-06，RiverAtlas v1.9.0，32页。用户指出第08页鼠标移动来回跳，顺滑不等于变慢，并要求稍提速、换方法。

## 复现与根因

在离线1920×1080下，鼠标沿y540从x660单向移到1250，16px步长/90ms间隔；旧版选图反复出现1→0→1→0（图件内部索引）。完整扫过更出现1→0→1→0→1→2→1→2→3→2→3→2，鼠标无反向操作。三项候选为动态命中几何、80ms旧延时及动画重启。

单变量探测：只取消延时仍1→0→1→0；冻结图件几何后为1→0，没有再次选回。同一物理方向因大图重排而反复命中不同图片，是选图和展示共用移动表面的反馈循环。v1.8放慢至900ms不能消除该根因。

先将此最小复现加入tests/atlas-stability.test.cjs，旧版明确失败“单向移动却反复选回：1→0→1→0”；修复后同命令通过。

## 最终交互

固定四份预览图（桌面主图右侧、手机底部）与左目录负责选择，不因图件切换移动。主图只负责展示和点击原件，移除主图pointermove选图、80ms定时器与位移门槛。移动的图片不会再改变选择目标。图集显示预览、单图隐藏；选中与左栏/预览同步。

入图520ms power2.out，12px微位移、scale .985→1、opacity；出图240ms/−8px/scale1.01/淡出。较900ms稍快，减少大幅几何运动；只有完全不可见图重设入场状态，仍可见图重选时延续当前位置/透明度。暂停冻结、静态直接显示、后台与离页停止；触屏与键盘可选图。
